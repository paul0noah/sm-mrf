# How to Create TOPFAUST dataset

1. Download `FAUST_r` dataset in the format as it can be found in [this repo ](https://github.com/dongliangcao/unsupervised-learning-of-robust-spectral-shape-matching)
2. Install `libigl`, `polyscope`, `open3d`, `pymeshfix`, `scikit-learn`, `numpy`
3. adjust paths in the script `create_faust_topo.py` accordingly
4. run the script
